2. Datos que recogemos

Para generar tu carta de reclamación recogemos los siguientes datos:

  • Nombre completo o razón social
  • DNI, NIF o CIF
  • Dirección postal
  • Teléfono y email
  • Descripción del caso y documentos adjuntos

Estos datos se transmiten de forma segura a la API de Anthropic (Claude) para generar el documento. No se almacenan en ninguna base de datos propia.

3. Finalidad del tratamiento

Los datos se usan exclusivamente para:

  • Generar la carta de reclamación personalizada
  • Procesar el pago de la descarga en PDF (a través de Stripe)

4. Base legal

El tratamiento se basa en el consentimiento del usuario al utilizar el servicio, de acuerdo con el Reglamento General de Protección de Datos (RGPD) y la Ley Orgánica 3/2018 de Protección de Datos Personales (LOPDGDD).

5. Conservación de datos

Los datos introducidos en el formulario no se almacenan en ninguna base de datos. Se procesan en tiempo real para generar la carta y no se conservan una vez finalizada la sesión.

Los datos de pago son gestionados íntegramente por Stripe y no son accesibles por ReclamaYa.

6. Transferencias internacionales

Para la generación de la carta se utiliza la API de Anthropic (Estados Unidos), empresa adherida al Marco de Privacidad de Datos UE-EE.UU. y que cumple con las garantías adecuadas establecidas por el RGPD.

7. Tus derechos

Como usuario tienes derecho a:

  • Acceso: conocer qué datos tratamos sobre ti
  • Rectificación: corregir datos inexactos
  • Supresión: solicitar la eliminación de tus datos
  • Portabilidad: recibir tus datos en formato estructurado
  • Oposición: oponerte al tratamiento de tus datos

Puedes ejercer estos derechos escribiendo a [TU EMAIL]. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos (aepd.es).

8. Cookies

Este sitio web únicamente utiliza cookies técnicas necesarias para el funcionamiento del servicio. No utiliza cookies de seguimiento ni publicidad.
